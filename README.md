# The Cornerstone Scorecard

**Your strength is in the Body.** A free tool to help a church see how it is connected — many members, one Body (after 1 Corinthians 12).

## Use it

📱 **Open the app:** https://inconstantsnap-commits.github.io/cornerstone-scorecard/

It works in any phone or computer browser — no account, no sign-up, nothing to install.

⬇ **Or download it:** save `index.html` from this repo to your device and open it. The whole tool is that one file, and it works offline. (Tip: export a JSON backup now and then — your collection lives on your device.)

## How it works

1. Each person fills in the Cornerstone Scorecard: the household they belong to, the household their body exists to serve (the star), and a chip — **Faithful**, **Growing**, or **Scattered** — for every connection on the board.
2. Enter each person's card into the tool (or pass one phone around the room).
3. Open **Combined** to see the whole church on one picture: a wheel of every connection, a grid of circles (a dotted ring means the room is split on that circle), and a **Talk it through** panel — pick any household to see how the room marked it and get the two questions that start the conversation: *What does each side know that the other doesn't?* and *Who could move one rating in the next 90 days?*
4. Several rooms or several churches? Each keeps its own collection, then one person imports them all into a single device for the full picture (**Share** tab: JSON export/import; CSV for spreadsheets).

## Collection codes — many groups, one tool

Every scorecard is stamped with a **collection code**, so gatherings stay sorted when several groups use the tool over time.

- Before a gathering, set a code in the app (type your own, like `IMMANUEL-OCT26`, or tap **Generate one**). Everyone entering cards at that gathering uses the **same code on every phone** — the code travels inside every exported file.
- **People** and **Combined** can be filtered to a single collection, or show everything at once.
- With two or more collections on a device, **Combined → Compare two gatherings** shows how the picture changed: overall Faithful / Growing / Scattered, and which threads moved up or slipped back.
- A coordinator can hand off or receive **one collection at a time** (Share tab → "Download this collection only"), so churches keep their own data and share only what they mean to.
